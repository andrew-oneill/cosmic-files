This is a personal fork of pop-os/cosmic-files that adds a Miller columns view on the
`miller-columns` branch. It is not upstreamed. Design, status and how to build, test and
screenshot it headless are in [docs/miller-columns.md](docs/miller-columns.md).

## Columns view

macOS Finder's column view is the reference for how the columns view behaves: selection,
clicks, right-clicks, menus, drag and drop, keyboard navigation and layout. When unsure, match
Finder. Keep the list and grid views' upstream behaviour unless asked otherwise.
